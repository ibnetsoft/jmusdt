# 회원등급

- 기본 등급은 일반회원과 정회원이다. 신규 가입자는 일반회원이며 이메일 확인만으로 정회원이 되지 않는다.
- 취소 완료되지 않은 본인 포인트 구매 누적 50,000 P 이상이면 자동 승급한다. 추천·후원 조직의 매출은 포함하지 않는다. 구매와 승급·후원 자동 배치·보상 스냅샷은 같은 트랜잭션에서 처리한다.
- `/admin/grades`에서 구매 이력이 없는 일반회원을 사유와 함께 정회원으로 수동 지정할 수 있다. 정회원 승급 후 환불에 따른 자동 강등은 하지 않는다.
- 일반회원은 추천코드와 링크를 사용할 수 있지만 조직도에 등록되지 않고 수당도 수령하지 않는다. 정회원은 이메일 인증과 정상 계정 상태를 함께 충족해야 조직·수당에 참여한다.
- 추가 등급 생성 시 정회원과 동일한 조직·수당 참여 자격을 부여할지 선택한다. 기본값은 미부여이며 이름만 바꿔 수당 자격을 얻을 수 없다. 추가 등급과 정회원은 자동 승급으로 덮어쓰지 않는다. 등급은 관리자 권한과 별개다.
- 일반회원으로 수동 변경하면 조직·수당 자격이 중단된다. 이후 구매 시 기준을 충족하면 다시 자동 승급한다. 기존 후원 순번은 재배정하지 않는다.
- 기본 정회원의 내부 식별 코드 `vip`는 데이터 호환을 위해 유지하며 화면의 명칭은 정회원으로 통일한다.
- 적용 순서는 `db/member-grades.sql` → `db/network-rollup.sql` → `db/daily-pools.sql`이며 `npm run db:apply`에 포함된다.
