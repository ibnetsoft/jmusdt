# 추천·후원 조직도

- 모든 회원의 추천코드는 가입 시 자동 생성된다. `/mypage` 또는 지갑의 마이페이지에서 코드와 추천 가입 링크를 복사할 수 있다. 일반회원도 추천할 수 있다.
- 가입 시 추천 관계를 한 번 확정하며 이후 사용자 메타데이터 변경으로 추천인을 바꿀 수 없다. 추천인 없이 가입한 회원에게 임의의 추천인을 붙이지 않는다.
- 이메일 인증 후 정회원이 되는 시점에 조직에 등록한다. 자동 구매 승급과 관리자 수동 지정 모두 같은 규칙을 따른다. 일반회원은 조직도에 표시하지 않는다.

## 자동 후원 배치

직접 추천한 회원 중 **정회원이 된 순서**를 추천인별로 기록한다. 가입만 한 순서는 사용하지 않는다.

| 정회원 등록 순번 | 후원인 |
|---|---|
| 1·2·4·5·7·8 등 3의 배수가 아닌 순번 | 원래 추천인 |
| 3 | 원래 추천인의 1대 상위 추천인 |
| 6 | 원래 추천인의 2대 상위 추천인 |
| 9 | 원래 추천인의 3대 상위 추천인 |
| 12·15 등 | 같은 방식으로 4·5대 이상 상위 추천인 |

추천 관계는 유지하고 후원 관계만 자동 롤업한다. 필요한 상위 추천인이 없으면 배치 대기와 사유를 표시한다. 대상 추천인이 일반회원이면 그 대상의 정회원 등록을 기다린다. 다른 회원에게 임의로 대체 배치하지 않는다. 재로그인·재승급·마이그레이션 재실행으로 순번을 바꾸지 않는다.

기존 데이터에 정회원 등록 이력이 없으면 최초 적용에 한해 가입일·회원 ID 순으로 순번을 부여하고 감사 기록을 남긴다. 기존 수당 스냅샷과 지급 내역은 수정하지 않는다.

## 화면과 권한

`/organization`에서 추천·후원 조직도, 단계 선택, 하위 조직 이동, 경로 탐색, 확대·축소, 드래그·두 손가락 확대, 전체화면을 제공한다. 좌우 수동 배치 기능은 제거했다. `POST /api/organization`과 이전 배치 SQL 함수는 수동 배치를 거절한다.

본인 산하만 조회할 수 있다. 이름·추천코드·가입일·정회원 등록 순번·유효 포인트 구매 합계를 표시하며 다른 회원의 이메일·전화·지갑 잔액은 반환하지 않는다. 조회 한도는 500명·전체 선택 최대 50단계다.

`db/network-rollup.sql`은 `db/member-grades.sql` 다음에 적용한다. 거래 잠금으로 동시 승급의 중복 순번을 막고, 권한 제한·서버 전용 트리거로 회원이 자신의 수당 자격을 변경하지 못하게 한다. `tests/network-rollup.test.ts`에서 정회원 등록 순서, 3·6·9·12·15 롤업, 상위 부재 대기, 재승급·재실행, 정회원 수당 자격과 구매 당일 보상 수령인을 검증한다.
