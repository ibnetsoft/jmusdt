# 추천·후원 조직도

지갑 메뉴의 **조직도**(`/organization`)에서 사용합니다. Live 모드의 인증된 회원이 대상입니다.

## 사용 방법

1. 본인 추천 코드 또는 추천 링크를 복사해서 전달합니다.
2. 신규 회원은 링크로 가입하거나 가입 화면에 추천 코드를 입력합니다. 이메일 확인 후 처음 로그인하면 미배치 회원 목록에 표시됩니다.
3. **후원 조직도**에서 본인이 추천한 미배치 회원을 선택하고, 본인 산하 회원의 비어 있는 **좌 배치 / 우 배치**를 누릅니다.
4. 확인 창에서 확정합니다. 배치 후 추천인은 유지되며 후원 위치만 정해집니다. 확정된 위치는 이동할 수 없습니다.

추천 조직도는 가입 때 정해진 추천 관계, 후원 조직도는 좌·우 배치 관계를 보여줍니다. 회원을 누르면 해당 하위 조직으로 이동하며 경로·뒤로·처음 버튼으로 돌아갑니다. 단계 선택, 확대·축소, 드래그·두 손가락 확대, 전체 화면을 지원합니다.

기존 회원은 추천 코드가 자동 생성되지만 과거 추천 관계를 임의로 추정하지 않습니다. 추천 코드 없이 가입한 회원도 자동으로 다른 추천인에게 연결하지 않습니다. 추천 관계는 가입 시 고정되며 사용자 메타데이터를 나중에 수정해도 변경되지 않습니다.

## 데이터와 권한

- `db/organization.sql`: 회원 네트워크, 가입 트리거, 산하 확인 함수, 배치 함수 및 RLS.
- `GET /api/organization`: 본인 산하만 조회. 이름·추천 코드·가입일·취소 제외 구매 합계를 표시하며 이메일·전화·지갑 잔액은 반환하지 않습니다. 구매 합계는 USDT와 포인트의 1:1 기준입니다.
- `POST /api/organization`: 본인이 직접 추천한 활성·인증 회원만 본인의 후원 산하 빈 자리에 배치합니다.
- 트랜잭션 잠금과 슬롯 유일 제약으로 동시 중복 배치를 방지합니다. 순환·본인 배치·타 조직 배치·배치 후 이동은 거절하며, 같은 배치 재요청은 중복 처리하지 않습니다. 감사 로그를 남깁니다.
- 브라우저에는 네트워크 수정 권한과 배치 SQL 실행 권한이 없습니다. 인증과 요청 출처를 확인한 서버 API만 실행합니다.
- 조회 한도는 500명, 전체 선택은 최대 50단계입니다. 한도에 도달하면 하위 회원을 눌러 추가 탐색합니다. 미배치 목록도 500명 단위로 표시합니다.

`npm run db:apply`에 스키마 적용이 포함됩니다. 이 기능에는 추천 수당·후원 수당 등 마케팅 보상 계산이 포함되지 않습니다.

## 참고 프로젝트

`ibnetsoft/viagra` 커밋 `a67538223795703c3d19aec5b0036605228ec4d4`의 `member-organization.tsx`, `actions.ts`의 조직 조회·배치 처리와 추천 배치/조직 깊이 관련 마이그레이션을 참고했습니다. JMUSDT의 인증·DB·화면 구조에 맞춰 구현했습니다. 좌·우 수동 배치 방식이며 wallet 프로젝트의 3/6/9 자동 배치 규칙은 적용하지 않습니다.

## 검증

- `npm test`: 조직도 포함 20개 테스트 통과. 슬롯 충돌·산하 권한·순환·이동 금지·추천 관계 고정·SQL 권한 확인.
- `npm run typecheck`, `npm run build` 통과.
- 실행 중인 Live 서버에서 `npx tsx scripts/verify-organization.ts --test-account`: 임시 Supabase 회원의 추천 가입·로그인·미배치 조회·좌우 배치·중복 요청·접근 거절·추천 관계 보존을 실제 API와 DB로 확인하고 QA 데이터를 정리합니다. 서비스 역할 키는 로컬 QA에만 사용합니다.
- 기존 상품 업로드·구매·전환·취소·환불 회귀 검증 통과. 금융 검증 데이터는 DB 트랜잭션을 롤백했습니다.
- 브라우저 자동화 런타임 오류로 화면 조작 검증은 수행하지 못했습니다.
