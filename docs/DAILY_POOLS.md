# 복주머니·보물상자 일일 분배

- 관리자가 상품마다 회사에 적립할 복주머니P와 보물상자P를 각각 정수 P로 입력한다. 상품 결제 시 구매자에게 바로 지급하지 않고 두 일일 풀로 나누어 적립한다. 지급 재원은 판매대금이며 일반 상품의 직접 보상·데일리 총액과 두 일일 적립액의 합은 상품 가격 이하여야 한다. 지정된 369일 패키지의 데일리 전용 예외는 MARKETING.md를 따른다.
- 관리자는 상품을 일반 상품, 복주머니패키지(350,000 P), 보물상자패키지(3,500,000 P)로 지정한다. 주문 당시 패키지 종류와 수량을 보존한다. 패키지를 보유하는 동안 매일 참여하며 수량에 비례해 나눈다.
- 한국 시간 하루 동안 발생한 매출을 다음 날 00:00에 마감·배당한다. 이전 주마감 정책은 최신 요청에 따라 일배당으로 변경했다. Vercel Cron은 매일 UTC 15:00에 호출하며 플랫폼 지연 시 실제 지급은 늦어질 수 있다. 누락된 마감은 이후 실행이나 관리자의 재처리로 복구한다.
- 일반 포인트는 소수점 6자리까지 지급한다. 회원별 몫은 해당 풀 × 보유 수량 ÷ 전체 보유 수량을 소수점 6자리 아래에서 내린다. 참여자가 없거나 계산 후 남은 금액은 이월하지 않고 회사 매출에 남긴다.
- 취소 확정된 패키지는 미분배 일일 마감에서 제외한다. 상품 주문이 분배 전에 취소되면 해당 미분배 적립분을 취소한다. 이미 마감된 지급은 소급 변경하지 않는다. 취소 요청 중인 주문은 확정 전까지 유효하다.
- 적립·취소·분배는 원장에 별도 기록하고 마감일과 종류의 중복 처리를 막는다. 회원에게는 패키지 보유량과 일일 지급 내역, 관리자에게는 적립·마감·회사 잔여 내역을 표시한다.
- 새 기능 활성화 전의 과거 주머니 지급 기록은 새 회사 풀로 자동 전환하지 않는다. 실제 데이터가 있다면 별도 대사와 이행 정책이 필요하다.

- 수령인은 이메일 인증·정상 상태·정회원(또는 동등 참여 등급) 자격을 충족해야 한다. 마감 시각 전에 활성화된 자격과 구매한 패키지만 해당 마감에 참여한다. 처리 시점에 자격을 상실한 회원에게는 지급하지 않는다.
- 회원의 패키지 보유 수량은 정수 개수이며, 배당액은 일반 포인트 잔액에 소수점 6자리까지 지급한다. 회사에 남긴 미배분액은 다음 날로 이월하지 않는다.
- `db/daily-pools.sql`의 `daily_pool_entries`, `daily_pool_runs`, `daily_pool_payments`에 적립·마감·개별 지급 내역을 기록한다. `daily:pool_reserve` 원장 계정으로 재원을 대사한다.
